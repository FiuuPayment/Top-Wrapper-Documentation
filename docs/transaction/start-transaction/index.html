Start a Transaction

Once onLoginSuccess() has fired, call startTransactionFlow to begin a payment:

tapSDK.startTransactionFlow(
    this,               // context
    uniqueId,           // generated through the merchant portal
    orderId,            // your order reference
    amount,             // String, no decimal point — see note below
);
ParameterTypeNotes
contextContextTypically the calling Activity.
uniqueIdStringGenerated through the merchant portal.
orderIdStringYour own order reference.
amountStringNo decimal point — see below.

Amount Format​

caution

Amounts are strings without a decimal point, expressed in the currency's smallest unit. If the amount is 5.99, pass "599". If the amount is 599.00, pass "59900".

From here, the SDK drives the flow through TapCallback — card tap, possible signature capture, and a final result. See Flow Overview for the full event sequence, and Capture Signature if your flow requires it.

Cancelling Mid-Flow​

If you need to cancel before a result comes back (e.g. the user backs out while waiting for a card tap), see Cancel a Transaction — Abort an In-Flight Transaction. To void a transaction that already completed, see Cancel a Transaction — Void a Completed Purchase.
