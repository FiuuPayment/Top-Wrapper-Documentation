onTransactionResult resultCode Reference​

Different from statusCode

This is a separate code system from the statusCode string field inside the JSON payload (documented above). resultCode is the int passed as onTransactionResult(int resultCode, String json)'s first argument by the SDK itself — check resultCode first to know whether the call succeeded at the transport/reader level at all, then parse json for the payload-level statusCode.

resultCodeMeaning
0Success — parse json for the transaction outcome.
200Success — parse json for the transaction outcome.
7004Card declined.
7005Card failed.
7006No app error (no matching EMV application on the card).
7007Failed — fallback allowed.
7008Card expired.
7020Online fail.
7024Card cancelled.
7028Card timeout.
7030Card error.
7052Reader config error.
7053Select next error.
7054Require CDCVM.
7055End application error.
7056Reserved — no message observed in a working integration. Contact Fiuu if you encounter it.
(any other value)Unknown — log the raw resultCode and json and contact Fiuu.

Any resultCode other than 0/200 indicates the transaction did not complete; treat it as a failure without needing to parse json.
